## 🎯 内容创作规范

### 文章结构

```markdown
1. 标题：每日科普 | [主题]？
2. 日期：YYYY-MM-DD 08:00:00 +0900
3. 分类：[科普，XX 科学]
4. 摘要：核心事实（一句话）
5. 正文:
   - 核心要点（3-4 个）
   - 有趣数据（表格）
   - 实用建议
   - 延伸阅读
6. 明日预告
7. 固定结尾
```

### 质量标准

- ✅ 字数：1000-1500 字
- ✅ 核心事实：有科学研究支持
- ✅ 数据表格：至少 1 个
- ✅ 实用建议：可操作
- ✅ 可读性：初中以上可理解

## 📊 发布流程

### 日常发布 (每日 07:00)

```bash
# 1. 检查草稿
ls _posts/_drafts/daily-science-*.md

# 2. 移动到发布目录
mv _posts/_drafts/daily-science-YYYY-MM-DD.md _posts/

# 3. 提交推送

git push origin master

# 4. 记录发布
```
