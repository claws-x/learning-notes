## ✅ 发布标准 (必须全部满足)

### 1. 字数要求

| 文章类型 | 最低字数 | 推荐字数 |
|----------|----------|----------|
| 技术教程 | 3000 字 | 4000-6000 字 |
| 实战经验 | 3000 字 | 4000-5000 字 |
| 深度科普 | 3000 字 | 4000-6000 字 |
| 项目复盘 | 2500 字 | 3000-4000 字 |

**硬性要求**: 低于最低字数一律不发

### 2. 引用来源

**最少 3 个权威来源**:

```
✅ 合格引用:
├── 学术论文 (Google Scholar, PubMed, IEEE)
├── 官方文档 (Apple Developer, MDN, W3C)
├── 权威书籍 (O'Reilly, Manning, 机械工业)
├── 官方研究 (NASA, NIH, 政府机构)
└── 知名媒体 (Nature, Science, MIT Tech Review)

❌ 不合格引用:
├── 维基百科 (可作为起点，不能作为来源)
├── 自媒体文章 (公众号，知乎专栏)
├── 论坛帖子 (Stack Overflow 除外)
└── 无作者博客
```

**引用格式**:
```markdown
[^1]: 作者。"文章标题". 期刊/网站，年份. 链接
[^2]: 作者。"书名". 出版社，年份. 页码
```

### 3. 数据验证

**所有数据必须有出处**:

```
❌ 错误写法:
"研究表明，睡眠不足会降低工作效率"

✅ 正确写法:
"哈佛医学院 2019 年研究显示，连续 24 小时不睡觉
认知能力下降相当于血液酒精浓度 0.1% [^1]"

[^1]: Walker, M. "Why We Sleep". Scribner, 2017. p.134
```

### 4. 内容深度

**必须包含三个层次**:

```
📖 What (是什么) - 基础概念
   └── 定义、现象、表现

🔬 Why (为什么) - 原理机制
   ├── 科学依据
   ├── 背后原理
   └── 因果关系

💡 How (怎么做) - 实践应用
   ├── 具体方法
   ├── 注意事项
   └── 案例演示
```

### 5. 原创价值

**必须满足至少一项**:

- ✅ 原创研究成果
- ✅ 独特实战经验
- ✅ 深度分析见解
- ✅ 系统性知识整理
- ✅ 创新方法论

## 📝 创作流程

### 标准流程 (SOP)

```
1. 选题调研 (2-3 小时)
   ├── 收集 10+ 篇相关文献
   ├── 整理核心观点
   └── 确定文章角度

2. 大纲设计 (1 小时)
   ├── 确定核心论点 (1 个)
   ├── 设计分论点 (3-5 个)
   └── 准备案例和数据

3. 初稿撰写 (4-6 小时)
   ├── 快速写作，不求完美
   ├── 标注引用位置
   └── 确保字数达标

4. 深度优化 (2-3 小时)
   ├── 补充缺失引用
   ├── 核实所有数据
   ├── 增加原创见解
   └── 优化语言表达

5. 审核检查 (1 小时)
   ├── 字数检查 (≥3000)
   ├── 引用检查 (≥3 个)
   ├── 数据核实 (有出处)
   └── 价值评估 (有应用)

6. 发布推广 (30 分钟)
   ├── 多平台分发
   ├── 社群推广
   └── 数据追踪
```

**总计**: 10-14 小时/篇

## 🔍 审核清单

发布前必须逐项检查：

### 基础检查
- [ ] 字数 ≥ 3000 字
- [ ] 标题准确，不标题党
- [ ] 分段清晰，可读性强
- [ ] 配图适当 (每 500 字 1 图)

### 内容检查
- [ ] 至少 3 个权威引用
- [ ] 所有数据有出处
- [ ] 有 What/Why/How 三层结构
- [ ] 有原创见解或实战经验

### 价值检查
- [ ] 读者能学到具体知识
- [ ] 读者能实际应用
- [ ] 读者能获得认知提升
- [ ] 对得起读者时间

### 技术检查
- [ ] 代码示例可运行
- [ ] 链接有效
- [ ] 格式正确
- [ ] 无错别字

## 📊 质量评分

每篇文章按以下维度评分 (1-5 分):

| 维度 | 权重 | 5 分标准 |
|------|------|----------|
| 内容深度 | 30% | 有独到见解，超越表面 |
| 引用质量 | 25% | 全部权威来源，格式规范 |
| 实用价值 | 25% | 可直接应用，效果可验证 |
| 原创性 | 15% | 有独特观点或研究 |
| 可读性 | 5% | 流畅易懂，结构清晰 |

**发布标准**: 总分 ≥ 4.0 分

## 🎯 执行承诺

### 对读者的承诺

1. **时间尊重**: 不浪费读者一分钟
2. **质量保证**: 每篇都是精品
3. **价值交付**: 读完必有收获
4. **诚信为本**: 不夸大，不虚假

### 对自己的要求

1. **宁缺毋滥**: 宁可少发，不发水货
2. **持续学习**: 每篇都要深入研究
3. **接受批评**: 欢迎读者监督
4. **持续改进**: 根据反馈优化
